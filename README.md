Playlist Maker 
1. Описание
Приложение для создания и управления плейлистами. 
Позволяет добавлять треки в плейлисты, создавать новые плейлисты и управлять ими.
Можно находит треки по интернет-сети. Можно добавлять избранные треки, которые будут сохранятся во вкладке "Избранное"

2. Технологии которые были использованы:

- Версия Android Studio: android-studio-2025.1.3.7
- Kotlin: 2.2.21
- min SDK: 29
- target SDK: 36

3. Как осуществляется сборка и запуск:

1) Клонируйте репозиторий
2) Откройте проект в Android Studio
3) Дождитесь синхронизации Gradle
4) Подключите физичское устройство или запускайте на эмуляторе (API 29+)
5) Нажмите Run или используйте комбинацию Shift + F10.
